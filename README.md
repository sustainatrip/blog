## 📖 Sobre

O **SustainaTrip Blog** é um projeto desenvolvido em **Jekyll**, hospedado gratuitamente no **GitHub Pages**, criado para compartilhar conteúdos sobre turismo sustentável, cultura, ecoturismo, gastronomia e experiências autênticas.

Nosso objetivo é inspirar pessoas a viajarem de forma mais consciente, valorizando comunidades locais, patrimônio cultural e conservação ambiental.

## ✍️ Criando um novo artigo

Basta criar um arquivo dentro da pasta:

```text
_posts/
```

Exemplo:

```text
2026-07-28-ponte-hercilio-luz.md
```

Modelo:

```markdown
---
layout: post
title: "Título do artigo"
date: 2026-07-28
author: SustainaTrip

categories:
  - Cultura

tags:
  - Florianópolis
  - Turismo

image: /assets/images/imagem.jpg
---

Seu conteúdo em Markdown começa aqui.
```

## 🚀 Executando localmente

Instale as dependências:

```bash
bundle install
```

Depois execute:

```bash
bundle exec jekyll serve
```

Abra:

```text
http://localhost:4000
```

## 🌍 Deploy

O deploy é realizado automaticamente pelo **GitHub Actions**.

Sempre que houver um novo commit na branch principal, o site será compilado e publicado no **GitHub Pages**.
